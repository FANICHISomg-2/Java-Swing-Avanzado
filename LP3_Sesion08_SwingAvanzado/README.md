# LP3 - Sesión 08: Java Swing Avanzado
Universidad Católica de Santa María - EPIS - Lenguajes de Programación III

Ejercicios propuestos:
1. `AppProducto.java` - Binding de datos manual (clase Producto)
2. `AppTemperaturas.java` - Gráfico de líneas con Graphics2D
3. `AppEfectos.java` - Efectos de sonido con Clip (aplausos.wav, campana.wav, explosion.wav)
4. `AppReproductor.java` - Reproducir / pausar / reanudar (musica.wav)

Los archivos .wav van en la raíz del proyecto (junto a `src`).
